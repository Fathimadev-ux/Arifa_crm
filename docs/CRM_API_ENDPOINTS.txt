ARIFA CRM - WHICH ENDPOINT IS FOR WHAT
Source: docs/CRM_API.pdf (version of 18 Nov 2026) - 104 endpoints
Grouped by CRM screen, in menu order.

HOW TO READ
  METHOD  PATH                                  What it does                                   Who can use it
  (MFA)  = must be signed in with the authenticator app (6-digit code from the phone app)
  [NEW]  = new in the 18 Nov PDF; the CRM screens don't use it yet
  Roles: sales, manager, md, admin. "all" = all four roles.
  Base path: every path starts with /v1 (except the public key). Money is a text like "12500.00".

==========================================================================================
1. LOGIN AND ACCOUNT (Login screen, My account)
==========================================================================================
  POST   /v1/auth/login                       Step 1: email + password; says which 2nd step is offered      public
  POST   /v1/auth/mfa/totp                    Step 2 with the authenticator app code (full session)         public
  POST   /v1/auth/mfa/email/send              Step 2 fallback: email a 6-digit code (valid 10 min)          public
  POST   /v1/auth/mfa/email/verify            Step 2 with the email code (no approvals in this session)    public
  POST   /v1/auth/refresh                     Get a new access token (token lasts 15 min)                   public
  POST   /v1/auth/logout                      Log out: ends this browser's session                          public
  GET    /v1/auth/me                          Who is signed in: name, role, languages                       all
  POST   /v1/auth/totp/enrol                  My account: start setting up the authenticator app            all
  POST   /v1/auth/totp/confirm                My account: first code switches the authenticator on          all
  POST   /v1/auth/password                    My account: change password (ends other sessions)             all
  POST   /v1/auth/password/reset/start        Forgot password: send a code to the work email                public
  POST   /v1/auth/password/reset/finish       Forgot password: code + new password (min 12 chars)           public
  GET    /.well-known/jwks.json               Public key to check login tokens (for other systems)          public
  PUT    /v1/users/{user_id}/availability     "I'm away" / "I'm back", with a backup person                 all

4. DEAL PAGE (opened by clicking a deal)
==========================================================================================
  Reading the deal
  GET    /v1/deals/{deal_id}                  The deal: buyer, company, requirement, stage, AI summary      all
  GET    /v1/deals/{deal_id}/timeline         Every message, call, stage change and AI action               all
  GET    /v1/deals/{deal_id}/quotes           All quote versions (to compare two side by side)              all

  Quotes and approval
  POST   /v1/deals/{deal_id}/quotes           Ask the backend to build the quote from the price list        all
  POST   /v1/deals/{deal_id}/quotes/revise    Edit a quote -> new version (below minimum goes to manager)   all
  POST   /v1/deals/{deal_id}/quotes/manual    A quote priced by hand, then approved as usual                all
  GET    /v1/quote-versions/{version_id}      One quote version: lines, terms, delivery, totals             all
  GET    /v1/quote-versions/{version_id}/costs Cost build-up per line (not on v1 screens)                   md
  POST   /v1/approvals/{approval_id}/decision Approve / reject / ask for correction (MFA)                   sales, manager, md
  POST   /v1/deals/{deal_id}/offer            Below-minimum alert: set an approved special price (MFA)      manager, md

  Moving the deal
  POST   /v1/deals/{deal_id}/stage            Move to another stage (Lost needs a reason)                   all
  POST   /v1/deals/{deal_id}/payments         Confirm the advance payment -> stage Payment (MFA)            sales, manager, md
  POST   /v1/deals/{deal_id}/won              Mark Won; the order is created (MFA)                          sales, manager, md
  POST   /v1/deals/{deal_id}/reopen           Reopen a Lost deal; the AI stays paused (MFA)                 manager, md

  Talking to the buyer
  POST   /v1/deals/{deal_id}/messages         Reply on WhatsApp / email from the company number;            all
                                              refused if the price isn't in an approved quote;
                                              after 24 h silence resend with the re-open template
  POST   /v1/deals/{deal_id}/call             Click-to-call: rings the salesperson first, then the buyer    all
  POST   /v1/deals/{deal_id}/opt-out          Record that the buyer said stop (cancels follow-ups)          all
  POST   /v1/deals/{deal_id}/personal-contact-shared  Note that a personal contact was shared               all

  Who handles it
  POST   /v1/deals/{deal_id}/ai               Pause the AI (take over) or hand back to the AI               manager, md
  POST   /v1/deals/{deal_id}/reassign         Give the deal to another salesperson                          manager, md
  POST   /v1/deals/{deal_id}/takeover         MD takes the deal over; salesperson becomes read-only         md
  POST   /v1/deals/{deal_id}/handback         End the takeover; salesperson can work again                  md

  Order (also on the Orders screen)
  PATCH  /v1/deals/orders/{order_id}          Order status: in production -> ready -> shipped -> delivered  manager, md

  POST   /v1/users/{user_id}/unlock           Unlock after too many wrong passwords (MFA)                   admin, md

  Kill switch tab
  GET    /v1/admin/kill-switch                Current level and what it stops                               admin, manager, md

WHAT IS NEW IN THE 18 NOV PDF (to build in the CRM)
==========================================================================================
  1. Product workbook (3 endpoints): download / preview / apply one Excel file for products,
     prices and website details. Screen "Product workbook" under Products.
  2. Message texts (5 endpoints): edit the AI's fixed phrases, buyer messages and staff alerts;
     AI translates into 5 languages. New Settings tab "Message texts".
  3. Company details (4 endpoints): name, address, TRN, bank details and logo printed on quotes.
     New Settings tab "Company".

  5. Currency rates are now automatic (daily at 06:05 Dubai); show "automatic" or
     "entered by manager" next to each rate.

COMMON ANSWERS (errors)
==========================================================================================
  401  Not signed in / token expired -> refresh, else go to login
  403  Wrong role, someone else's deal, authenticator sign-in needed, or MD took the deal over
  404  Not found or not visible to this user
  409  Someone else changed it -> reload
  422  A business rule said no -> show the message (e.g. unapproved_price, window_closed, opt_out)
  429  Locked out after too many tries -> wait 15 minutes
  503  Email or calls service down -> try again later
